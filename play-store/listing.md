# ToolTrack Google Play listing

## App name

ToolTrack

## Short description

Scan, check out, return, and track every tool your team uses.

## Full description

ToolTrack gives contractors, maintenance teams, construction crews, and small businesses a simple way to know where every tool is and who has it.

Attach a QR code to a tool, scan it with an Android phone, and check it out in seconds. Employees can return or transfer tools while managers see current status and a complete activity history.

Core features:

- Scan tool QR codes with the camera
- Check tools out to yourself
- Record the job, location, condition, and expected return date
- Return or transfer tools
- See available, checked-out, overdue, damaged, and missing tools
- View the current holder and complete checkout history
- Add tool photos, serial numbers, categories, and purchase details
- Manage employees within a company account

ToolTrack does not collect GPS location. Job and location labels are entered by users and are shared only within their company account.
